# SIT307 8.1D – Sydney Housing Price Prediction

This repository contains the work completed for the SIT307
Machine Learning Mini Project.

## Project Goal

The aim of this project is to develop a machine learning system
for predicting residential property prices across selected Sydney
suburbs.

The project covers the complete machine learning workflow,
including:

- Data collection and preparation
- Exploratory data analysis
- Feature engineering
- Regression model development
- Model evaluation
- Prediction error analysis
- Web application deployment

## Current Working Dataset

The current working dataset contains 120 house sales from three
Sydney suburbs:

- St Clair – 40 properties
- Baulkham Hills – 40 properties
- St Ives – 40 properties
